The Modulon Programming Language

A C-inspired language built for simplicity and speed, keeping native performance and familiar syntax while eliminating unnecessary complexity.

Download Modulon Source Code

Modulon is a modern programming language designed around the familiar syntax and practicality of C while removing many of the frustrations and limitations of traditional C development.

Modulon is built to be simple, fast, portable, and suitable for both low-level and general-purpose software development. It inherits C's straightforward syntax while introducing a cleaner type system, easier declarations, safer memory handling, and a modern compilation toolchain.

Core Features

  • Low level programming
  • No LLVM
  • C-inspired syntax
  • Manual memory management
  • Automatic memory management
  • No manual memory management required for normal programming
  • No garbage collecting
  • var declarations for simple variable definition
  • Consistent types across m32 and POSIX targets
  • AOT compilation
  • JIT compilation
  • Built-in assembler support
  • Fast native compilation
  • Simple and accessible type system
  • Designed for portability
  • Intended to remain close to the hardware when necessary

One of Modulon's major goals is to retain the performance and control associated with C without requiring programmers to deal with every piece of complexity that C exposes.

For example, declaring a string can be as simple as:

var stringvar = "this and that";

The compiler can determine the required storage automatically rather than requiring the programmer to manually calculate or specify the string's size.

Modulon is therefore not simply intended to be a C replacement with a few additional features. It is designed as a language with its own philosophy: C-like simplicity, native performance, modern compilation, and less unnecessary complexity.

The project is being developed from the existing AneoC compiler technology while expanding it into a complete programming language and toolchain.
