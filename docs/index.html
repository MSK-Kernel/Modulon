Welcome to the Modulon home page!

Modulon, the Modulon programming language, is a C-inspired language built for simplicity and speed, keeping native performance and familiar syntax while eliminating unnecessary complexity. It supports both AOT and JIT compilation, as well as a built-in assembler.

We strive to keep Modulon simple, fast, portable, and suitable for both low-level and general-purpose development, and encourage everyone to contribute changes and help testing the beta builds. Our sources are readily and freely available via Git.
